# ADR-002：默认推理后端采用国产大模型 API（SenseNova）

- 日期：2026-08-31
- 状态：已接受

## 背景
需要为 RAG 推理选择 LLM 后端，候选包括国产 API（商汤 SenseNova、通义千问、DeepSeek）与海外 API。

## 结论
默认使用 SenseNova 商汤日日新（`glm-5.2`），通过 `LLM_PROVIDER` 环境变量可切换通义千问 / DeepSeek；`LLM_API_KEY/LLM_BASE_URL/LLM_MODEL` 可全局覆盖。

## 理由
- 医疗场景对数据出境敏感，国产 API 合规风险低
- 多 provider 抽象保留切换能力，避免供应商锁定

## 否决的方案
- **海外 LLM API**：医疗数据出境合规风险
- **锁定单一 provider**：供应商风险不可控

## 何时重新评估
模型能力/价格发生重大变化，或客户指定私有化部署时。
