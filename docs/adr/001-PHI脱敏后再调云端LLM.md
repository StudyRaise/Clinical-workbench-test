# ADR-001：PHI 先脱敏再调云端 LLM，应用层脱敏/还原

- 日期：2026-08-31
- 状态：已接受

## 背景
平台要把临床文书（谈话记录、出院小结、科研报告）发给云端大模型处理，其中包含患者隐私信息（PHI），存在合规风险。

## 结论
所有发往云端 LLM 的文本先经 `apps/inference/app/desensitize/` 识别并替换敏感字段，映射表本地加密保存，模型返回后再经 restorer 还原。

## 理由
- 满足医疗数据合规要求，患者身份信息不出院
- 脱敏放在推理服务应用层，对上层 BFF/前端透明

## 否决的方案
- **直接把 PHI 发给 LLM**：合规不可接受
- **只用本地模型**：运维成本高，模型能力不如云端 API

## 何时重新评估
监管政策变化，或医院要求全链路私有化部署时（已有 `compose.gpu.yml` 预案）。
